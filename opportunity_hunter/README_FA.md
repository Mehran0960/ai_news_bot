# شکارچی فرصت‌های درآمدی | Opportunity Hunter — نسخهٔ ۰٫۱

ماژولی مستقل در مخزن `Mehran0960/ai_news_bot` برای کشف فرصت‌های عرضه و تقاضا در بازار ایران. منطق OfferChin تغییر نمی‌کند و هیچ آگهی یا پیام فروشنده‌ای خودکار ارسال نمی‌شود.

## آنچه نسخهٔ اول انجام می‌دهد

- صفحه‌های عمومی عرضه‌کننده، بازار خدمات و بنچمارک قیمت را می‌خواند.
- RSS، Google News RSS و پیش‌نمایش عمومی بعضی کانال‌های تلگرام را برای سرنخ کالایی/خدماتی/عمده‌فروشی می‌خواند.
- ادعای تخفیف، قیمت‌های قابل استخراج، محدودهٔ خدمت، نظرهای تاریخ‌دار و نشانه‌های موجود در متن را جدا ذخیره می‌کند.
- تعداد متخصصان/خدمات فعال را رقابت عرضه‌کنندگان تلقی می‌کند، نه تعداد خریداران.
- خروجی JSON و Markdown می‌سازد و موارد مبهم را فقط در وضعیت اکتشافی نگه می‌دارد.

## اجرای محلی

```bash
python opportunity_hunter/scan.py
python -m unittest discover -s opportunity_hunter/tests -v
```

خروجی هر اجرا در `opportunity_hunter/output/latest.json` و `latest.md` نوشته می‌شود.

- اجرای دستی از تب Actions.
- پس از تغییر فایل‌های ماژول.
- روزانه ساعت ۰۵:۱۵ UTC، تقریباً ۰۸:۴۵ به وقت ایران.

هر اجرا ابتدا تست‌ها را اجرا می‌کند، سپس منابع عمومی را می‌خواند و گزارش را به‌شکل artifact برای ۱۴ روز ذخیره می‌کند. اجرای workflow تضمین نمی‌کند که همهٔ منابع موفق بوده‌اند؛ تعداد موفق/ناموفق در گزارش درج می‌شود.

## مرزهای عملیاتی

این نسخه فقط منابع عمومی را می‌خواند. هیچ login bypass، دور زدن محدودیت دسترسی، تماس/پیام فروشنده، معامله، پرداخت، درج آگهی یا تعهد به مشتری انجام نمی‌دهد. اطلاعات نامشخص به‌صورت نامشخص باقی می‌ماند. قبل از هر اتصال انتشار به دیوار/شیپور باید مجازبودن مسیر فنی و شرایط همان پلتفرم جداگانه بررسی شود.
