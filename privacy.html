سیاست حریم خصوصی

مربوط به OfferChin YouTube Uploader · آخرین به‌روزرسانی: ۲۰ اکتبر ۲۰۲۶

این سیاست توضیح می‌دهد ابزار خصوصی OfferChin YouTube Uploader چگونه داده‌ها را هنگام انتشار خودکار ویدئوهای آفِرچین در کانال یوتیوبی که مدیر پروژه کنترل می‌کند، پردازش می‌کند. این ابزار برای اتصال حساب کاربران دیگر ارائه نشده است.

داده‌هایی که پردازش می‌شوند

  • مجوز حساب یوتیوب: برنامه از OAuth 2.0 برای دریافت مجوز صاحب کانال استفاده می‌کند. مجوز درخواستی YouTube به برنامه امکان انجام برخی عملیات مرتبط با منابع یوتیوب را می‌دهد؛ کاربرد عملی این ابزار انتشار ویدئوها و ثبت نتیجهٔ آپلود در کانال تحت مدیریت صاحب پروژه است.
  • اطلاعات ویدئو: فایل ویدئو و اطلاعات لازم برای انتشار آن، مانند عنوان و توضیحات، به YouTube ارسال می‌شوند. پاسخ‌های فنی لازم برای تشخیص موفقیت یا خطای آپلود نیز پردازش می‌شوند.
  • اعتبارنامه‌ها: شناسه و رمز OAuth و Refresh Token در GitHub Actions Secrets نگهداری می‌شوند و برای اجرای گردش‌کار به‌صورت متغیرهای محرمانه در اختیار آن قرار می‌گیرند؛ این مقادیر نباید در کد عمومی مخزن ثبت شوند.

هدف و نحوهٔ استفاده

داده‌ها فقط برای مجازسازی اتصال به YouTube Data API، آماده‌سازی و انتشار ویدئوهای آفِرچین و بررسی نتیجهٔ عملیات پردازش می‌شوند. این وب‌سایت از فرم ثبت‌نام عمومی استفاده نمی‌کند و از طریق صفحه‌های ثابت آن، اطلاعات شخصی بازدیدکننده جمع‌آوری نمی‌شود.

ذخیره‌سازی و ارائه‌دهندگان خدمات

Google و YouTube داده‌های لازم برای تأیید مجوز و دریافت ویدئوهای آپلودشده را طبق سیاست‌های خود پردازش می‌کنند. GitHub برای میزبانی کد، نگهداری GitHub Actions Secrets و اجرای گردش‌کارها استفاده می‌شود. فایل‌های ویدئوی تولیدشده ممکن است به‌عنوان خروجی اجرای GitHub Actions تا سه روز نگهداری شوند؛ گزارش‌ها و فراداده‌های فنی نیز ممکن است برای عیب‌یابی و ثبت وضعیت انتشار باقی بمانند.

اشتراک‌گذاری و فروش

داده‌های حساب یوتیوب برای فروش، تبلیغات هدفمند یا فهرست‌سازی کاربران استفاده نمی‌شوند و به اشخاص ثالث مستقل فروخته نمی‌شوند. انتقال داده فقط به ارائه‌دهندگان فنی یادشده و تا حد لازم برای اجرای عملکرد برنامه انجام می‌شود.

مدت نگهداری و حذف

اعتبارنامه‌های OAuth تا زمان نیاز به اجرای خودکار در GitHub Actions Secrets باقی می‌مانند. صاحب حساب می‌تواند دسترسی برنامه را از تنظیمات امنیتی حساب Google لغو کند و Secretهای مربوطه را از تنظیمات مخزن GitHub حذف کند. خروجی‌ها و گزارش‌های ذخیره‌شده نیز می‌توانند از بخش Actions مخزن حذف شوند.

امنیت

اعتبارنامه‌ها به‌جای قرارگرفتن در فایل‌های کد، در Secretهای GitHub Actions نگهداری می‌شوند و ارتباطات API از طریق HTTPS انجام می‌گیرد. بااین‌حال، هیچ روش انتقال یا ذخیره‌سازی اینترنتی را نمی‌توان کاملاً بدون خطر تضمین کرد.

تغییرات و تماس

این سیاست در صورت تغییر نحوهٔ کار ابزار به‌روزرسانی می‌شود. برای پرسش‌های مربوط به حریم خصوصی، از نشانی تماس توسعه‌دهنده که در صفحهٔ رضایت OAuth این برنامه نمایش داده می‌شود استفاده کنید.

Privacy Policy

OfferChin YouTube Uploader · Last updated: October 20, 2026

This policy explains how the private OfferChin YouTube Uploader processes data while publishing OfferChin videos to a YouTube channel controlled by the project owner. The tool is not offered for connecting other users' accounts.

Data processed

  • YouTube authorization: OAuth 2.0 is used to obtain authorization from the channel owner. The requested YouTube scope permits certain operations on YouTube resources; the tool's intended operation is uploading videos and recording upload outcomes for the owner-managed channel.
  • Video information: Video files and publishing metadata such as titles and descriptions are sent to YouTube. Technical responses needed to determine upload success or failure are processed.
  • Credentials: The OAuth client ID, client secret, and refresh token are stored as GitHub Actions Secrets and supplied to workflows as secrets. They should not be committed to public source files.

Purpose and use

Data is used only to authorize the YouTube Data API connection, prepare and publish OfferChin videos, and check operation results. This static website has no public sign-up form and does not collect visitor personal information through its pages.

Storage and service providers

Google and YouTube process authorization and uploaded-video data under their own policies. GitHub hosts the code, stores GitHub Actions Secrets, and runs the workflows. Generated video files may be retained as GitHub Actions artifacts for up to three days. Technical logs and publishing metadata may remain for troubleshooting and publication status records.

Sharing and sale

YouTube account data is not sold, used for targeted advertising, or sold to independent third parties. Transfers are limited to the service providers described above as necessary to operate the tool.

Retention and deletion

OAuth credentials remain in GitHub Actions Secrets while needed for automated publishing. The account owner may revoke the app's access through their Google Account security settings, remove related repository secrets, and delete stored outputs or logs from the repository's Actions area.

Security

OAuth credentials are stored in GitHub Actions Secrets rather than source files, and API communications use HTTPS. No internet storage or transmission method can be guaranteed completely risk-free.

Changes and contact

This policy may be updated when the tool's operation changes. For privacy questions, use the developer contact address displayed on the app's OAuth consent screen.
