# OfferChin / آفِرچین

## پکیج بهینه‌سازی

سند [پکیج بهینه‌سازی OfferChin](docs/OFFERCHIN_OPTIMIZATION_PACKAGE_FA.md) تمام پیشنهادهای توسعهٔ فروش، انتخاب محصول، تصویر، ویدئو، کپشن، اعتمادسازی و سنجش عملکرد را جمع‌بندی می‌کند. این سند فعلاً فقط نقشهٔ راه پیشنهادی است و سیاست اجرایی جاری را تغییر نمی‌دهد.

## اصل عملیاتی

ابتدا کاندیداهای معتبر دیجی‌کالا را با discount_percent DESC و در تساوی با savings_toman DESC مرتب کنید؛ سپس گاردهای rolling 24h خانواده، برند و شباهت را اعمال کنید. کاندیدای مسدودشده را رد و بالاترین گزینهٔ بعدیِ مجاز را بررسی کنید؛ اگر همه مسدودند، انتشار نکنید. این گاردها امتیاز رتبه‌بندی نیستند و نباید با fallback نادیده گرفته شوند.

همیشه بین «هدف پروژه»، «رفتار فعلی کد» و «کار برنامه‌ریزی‌شده» تفاوت بگذارید. برای ادعای انتشار، post ID واقعی مقصد را بررسی کنید؛ موفقیت workflow به‌تنهایی اثبات انتشار عمومی نیست.

تمام تغییرات کد و تنظیمات OfferChin باید از مسیر PR مستند عبور کنند و در handbook و changelog ثبت شوند. اجرای زمان‌بندی‌شده‌ای که فقط دادهٔ runtime تولید می‌کند، از طریق Actions و state ledger ردیابی می‌شود.
