## اصل عملیاتی

پس از عبور از گیت سخت تقاضای تازه و اعتبارسنجی قیمت/موجودی/لینک، نامزدها با میانگین هارمونیک سه معیار تقاضای زنده، عمومیت کاربرد و جذابیت تخفیف واقعی مرتب می‌شوند. استطاعت، قیمت نهایی کالا، پیش‌پرداخت اقساط و سقف قیمتی هیچ نقشی در امتیاز یا فیلتر انتخاب ندارند. پست محصول حداکثر هر ۵۷ دقیقه یک‌بار زمان‌بندی می‌شود؛ گزینه‌های مازاد در صف باقی می‌مانند. تحریریه فقط در فاصلهٔ بین محصولات فرصت انتشار دارد و retry تحریریه نباید پست محصول سررسیدشده را عقب بیندازد. رتبهٔ پرفروش سیگنال نسبی دسته است، نه تعداد قطعی فروش؛ رشد نظرها نیز فروش نیست. کلیک و کمیسیون ورودی رتبه نیستند.

کنترل تنوع دسته و کاربرد مستقل و نرم است (پیش‌فرض ۶ ساعت) و فقط وقتی هیچ گزینهٔ غیرتکراری باقی نمانده باشد قابل‌چشم‌پوشی است؛ خانواده، برند و شباهت معنایی محدودیت سخت ۲۴ساعته دارند. همیشه بین «هدف پروژه»، «رفتار فعلی کد» و «کار برنامه‌ریزی‌شده» تفاوت بگذارید. برای ادعای انتشار، post ID واقعی مقصد را بررسی کنید؛ موفقیت workflow به‌تنهایی اثبات انتشار عمومی نیست.

تمام تغییرات کد و تنظیمات OfferChin باید از مسیر PR مستند عبور کنند و در handbook و changelog ثبت شوند. اجرای زمان‌بندی‌شده‌ای که فقط دادهٔ runtime تولید می‌کند، از طریق Actions و state ledger ردیابی می‌شود.
