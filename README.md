## اصل عملیاتی

همیشه بین «هدف پروژه»، «رفتار فعلی کد» و «کار برنامه‌ریزی‌شده» تفاوت بگذارید. برای ادعای انتشار، post ID واقعی مقصد را بررسی کنید؛ موفقیت workflow به‌تنهایی اثبات انتشار عمومی نیست.

تمام تغییرات کد و تنظیمات OfferChin باید از مسیر PR مستند عبور کنند و در handbook و changelog ثبت شوند. اجرای زمان‌بندی‌شده‌ای که فقط دادهٔ runtime تولید می‌کند، از طریق Actions و state ledger ردیابی می‌شود.
