# راهنمای فعال‌سازی Dayan Affiliate Relay

مقصد انتشار از قبل تنظیم شده است: @Iran_gajet. منبع از پیش‌نمایش عمومی وب تلگرام خوانده می‌شود؛ بنابراین به Termux، ورود به حساب شخصی یا Telethon Session نیاز نیست.

## مرحله اول — ثبت توکن ربات در GitHub

1. مطمئن شو توکن متعلق به همان رباتی است که در @Iran_gajet ادمین و دارای مجوز انتشار است.
2. در گوشی این صفحه را باز کن: https://github.com/Mehran0960/ai_news_bot/settings/secrets/actions
3. گزینه New repository secret را انتخاب کن.
4. Name را دقیقاً TELEGRAM_BOT_TOKEN و Secret را توکن ربات بگذار و ذخیره کن.

توکن را در چت یا فایل کد قرار نده.

## مرحله دوم — نگاشت خصوصی لینک‌های افیلیت

هنگامی که آماده شدی، در همان صفحه یک Secret دیگر به نام AFFILIATE_LINKS_JSON بساز. مقدار آن باید یک شیء JSON باشد که کد محصول را به لینک شخصی واقعی همان محصول نگاشت می‌کند؛ نمونه ساختاری (این مقادیر ساختگی‌اند و نباید استفاده شوند):

{
  "38933": "https://YOUR-ACTUAL-PERSONAL-AFFILIATE-LINK",
  "29095": "https://YOUR-OTHER-ACTUAL-AFFILIATE-LINK"
}

لینک‌ها داخل مخزن عمومی نگهداری نمی‌شوند. اگر چند کد در یک پست وجود داشته باشد، سیستم فقط هنگامی خودکار انتخاب می‌کند که دقیقاً یک کد لینک معتبر داشته باشد. در غیر این صورت پست منتشر نمی‌شود تا نگاشت آن مشخص شود.

## مرحله سوم — فعال‌سازی زمان‌بندی

در https://github.com/Mehran0960/ai_news_bot/settings/variables/actions یک Repository variable با این مقدارها بساز:
- Name: DAYAN_AFFILIATE_RELAY_ENABLED
- Value: true

سپس در مخزن به Actions → Dayan Affiliate Relay (live) برو و Run workflow را اجرا کن. اولین اجرای موفق فقط baseline را ثبت می‌کند؛ ویدئوهای قدیمی ارسال نمی‌شوند.

## رفتار پیش‌فرض

- پایش https://t.me/s/Dayan_video هر ۳۰ دقیقه.
- مقصد: @Iran_gajet.
- سقف اولیه ۸ ویدئو در روز در ساعت‌های تهران 09:00، 11:00، 13:00، 15:00، 17:00، 19:00، 20:30 و 22:00.
- صف و شناسه‌های پردازش‌شده در state.json نگهداری می‌شوند.
- URL ویدئو نزدیک زمان انتشار تازه‌سازی می‌شود چون پیوندهای CDN ممکن است منقضی شوند.
- لینک شخصی روی دکمه خرید قرار می‌گیرد و متن افشای همکاری در فروش اضافه می‌شود.
- زمان‌بندی GitHub ممکن است تأخیر داشته باشد؛ زمان دقیق تضمین نمی‌شود.

## هزینه و امنیت

این نسخه از پیش‌نمایش عمومی رایگان تلگرام استفاده می‌کند و برای هر اجرا Apify را صدا نمی‌زند. توکن ربات فقط باید در GitHub Secrets ذخیره شود؛ لینک‌های افیلیت نیز با Secret جدا نگهداری می‌شوند.
