# راهنمای فعال‌سازی Dayan Affiliate Relay

مقصد تنظیم‌شده: @Iran_gajet. منبع فعلی: @Dayan_video. این نسخه از پیش‌نمایش عمومی Telegram استفاده می‌کند و نیازی به Termux یا ورود به حساب شخصی تلگرام ندارد.

## مرحله ۱ — توکن ربات مقصد

اگر از قبل Secret به نام TELEGRAM_BOT_TOKEN داری و این همان ربات ادمین @Iran_gajet است، لازم نیست دوباره بسازی. در غیر این صورت:

1. برو به https://github.com/Mehran0960/ai_news_bot/settings/secrets/actions
2. روی New repository secret بزن.
3. نام: TELEGRAM_BOT_TOKEN
4. مقدار: توکن رباتی که در @Iran_gajet مجوز انتشار دارد.

توکن را در چت یا فایل کد قرار نده.

## مرحله ۲ — دامنه فروشگاه شخصی دایان

در همان صفحه یک Secret بساز:
- Name: DAYAN_STORE_HOST
- Value: زیردامنه شخصی فروشگاهت در دایان، مانند yourshop.affdn.ir

این مقدار باید از حساب خودت در پنل دایان برداشته شود؛ از دامنه نمونه دیگران استفاده نکن. دایان در کانال رسمی خود الگوی لینک FastCart را به‌صورت /fastcart/[کد محصول] اعلام کرده است؛ کد داخل این لینک از پیام منبع استخراج می‌شود. اگر حساب یا زیردامنه شخصی دایان نداری، ابتدا باید ثبت‌نام را تکمیل کنی.

## مرحله ۳ — فعال‌سازی اجرای زمان‌بندی‌شده

در https://github.com/Mehran0960/ai_news_bot/settings/variables/actions یک Repository variable بساز:
- Name: DAYAN_AFFILIATE_RELAY_ENABLED
- Value: true

سپس در مخزن به Actions → Dayan Affiliate Relay (live) برو و Run workflow را اجرا کن. اجرای اول فقط baseline می‌سازد و محتوای قدیمی را منتشر نمی‌کند.

## رفتار پیش‌فرض

- بررسی عمومی https://t.me/s/Dayan_video هر ۳۰ دقیقه.
- مقصد انتشار: @Iran_gajet.
- سقف اولیه ۸ ویدئو در روز در ساعت‌های تهران 09:00، 11:00، 13:00، 15:00، 17:00، 19:00، 20:30 و 22:00.
- فقط پست‌هایی که ویدئوی مستقیم و دقیقاً یک کد محصول صریح دارند، خودکار وارد صف می‌شوند.
- کد محصول از عبارت‌هایی مانند «لینک کد 39612» استخراج می‌شود؛ قیمت، سایز یا اعداد بی‌برچسب به‌عنوان کد استفاده نمی‌شوند.
- اگر کد مبهم باشد، پست منتشر نمی‌شود. برای انتخاب دستی می‌توان شناسه پیام مبدأ را به کد در config/post_overrides.json وصل کرد.
- لینک خرید به‌شکل https://[فروشگاه‌شخصی].affdn.ir/fastcart/[کد] ساخته می‌شود؛ لینک‌های شخصی و توکن در کد عمومی ذخیره نمی‌شوند.
- GitHub Actions ممکن است با تأخیر اجرا شود و زمان دقیق تضمین نیست.

## آزمون بدون انتشار

Workflow «Dayan Relay Diagnostics» فقط منبع عمومی را می‌خواند و هیچ چیزی به کانال مقصد نمی‌فرستد. آن را پیش از فعال‌سازی live اجرا کن؛ اگر صفر URL ویدئویی یافت شد، انتشار خودکار را فعال نکن و لاگ را بررسی کن.
