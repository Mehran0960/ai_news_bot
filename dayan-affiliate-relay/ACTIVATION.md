# راهنمای فعال‌سازی نهایی

این فایل راهنمای فعال‌سازی نسخه live است. تا پایان تنظیمات، سیستم خاموش می‌ماند.

## 1) اول لینک‌های افیلیت را اضافه کن

در config/affiliate_links.json، کد محصول را به لینک واقعی شخصی همان محصول وصل کن. از قالب فرضی یا لینک عمومی استفاده نکن. اگر پست چند کد دارد، تنها وقتی انتخاب خودکار انجام می‌شود که دقیقاً یک کد در آن پست لینک معتبر داشته باشد؛ در غیر این صورت پست در صف می‌ماند.

برای انتخاب کد خاص یک پست، فایل config/post_overrides.json را به صورت شناسه پیام مبدأ به کد محصول پر کن.

## 2) نشست تلگرام را بساز

در اندروید با Termux یا روی رایانه Python و Telethon را نصب کن. فایل make_session.py را اجرا کن؛ API ID و API HASH از https://my.telegram.org گرفته می‌شوند. کد ورود را فقط در محیط محلی وارد کن. StringSession چاپ‌شده دسترسی به حساب تلگرام می‌دهد؛ آن را در GitHub Actions Secret با نام TELEGRAM_SESSION ذخیره کن و هرگز در چت یا کد قرار نده.

## 3) GitHub Actions secrets

در Settings → Secrets and variables → Actions → Repository secrets این موارد را بساز:

- TELEGRAM_API_ID
- TELEGRAM_API_HASH
- TELEGRAM_SESSION
- TARGET_CHANNEL

TARGET_CHANNEL باید کانال تحت مدیریت خودت باشد. همان حساب تلگرامی که StringSession متعلق به آن است باید اجازه ارسال در کانال مقصد را داشته باشد.

## 4) فعال‌سازی کنترل‌شده

در Settings → Secrets and variables → Actions → Variables، متغیر DAYAN_AFFILIATE_RELAY_ENABLED را با مقدار true تنظیم کن. این متغیر اجرای نسخه live را فعال می‌کند.

اولین اجرای موفق فقط شناسه آخرین پیام دایان را ثبت می‌کند و محتوای قدیمی را بازنشر نمی‌کند. پس از آن، تنها ویدئوهای جدید بررسی می‌شوند.

## 5) برنامه انتشار

بررسی کانال هر ۳۰ دقیقه انجام می‌شود. سقف شروع ۸ ویدئو در روز، در ساعت‌های 09:00، 11:00، 13:00، 15:00، 17:00، 19:00، 20:30 و 22:00 به وقت تهران است. GitHub Actions ممکن است با تأخیر اجرا شود، پس زمان دقیق تضمین نمی‌شود.

سیستم فقط وقتی لینک شخصی معتبر و کد محصول بدون ابهام باشد منتشر می‌کند. پست‌های فاقد نگاشت در صف می‌مانند؛ بنابراین لینک‌های محصول باید با روش رسمی پنل دایان تهیه شوند.
