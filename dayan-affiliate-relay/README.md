# Dayan Affiliate Relay

ابزار مستقل برای پایش کانال عمومی @Dayan_video هر ۳۰ دقیقه و انتشار حداکثر ۸ ویدئوی جدید در روز در کانال مقصد، همراه لینک افیلیت شخصی.

راهنمای اصلی فعال‌سازی: ACTIVATION.md

## رفتار ایمن سیستم

- در اولین اجرای موفق فقط شناسه آخرین پیام منبع را ثبت می‌کند؛ پیام‌های قدیمی بازنشر نمی‌شوند.
- فقط ویدئوهای جدید صف می‌شوند؛ اطلاعیه‌های متنی نادیده گرفته می‌شوند.
- هر ویدئو فقط زمانی منتشر می‌شود که برای کد محصول مرتبط یک لینک افیلیت HTTPS معتبر و بدون ابهام وجود داشته باشد.
- اگر کپشن چند کد دارد و فقط یک کد از آن‌ها لینک شخصی دارد، همان کد انتخاب می‌شود. اگر چند کد لینک دارند یا هیچ‌کدام لینک ندارند، پست منتشر نمی‌شود تا نگاشت دستی تعیین شود.
- لینک قبلی داخل کپشن منبع حذف می‌شود و لینک شخصی تو اضافه می‌گردد. متن افشای همکاری در فروش نیز افزوده می‌شود.
- وضعیت صف و شناسه پیام‌های پردازش‌شده در state.json نگهداری می‌شود؛ workflow فقط در صورت تغییر وضعیت فایل را commit می‌کند.

## فایل‌ها

- config/affiliate_links.json: نگاشت کد محصول به لینک افیلیت واقعی تو.
- config/post_overrides.json: نگاشت شناسه پیام مبدأ به کد محصول، برای پست‌های چندکدی.
- make_session.py: ابزار محلی برای تولید Telethon StringSession.
- run_relay.py: سازگارساز مرتب‌سازی پیام‌ها و انتخاب کد بدون ابهام.
- relay.py: منطق صف و انتشار.

## محدودیت مهم

ساخت خودکار لینک شخصی از روی کد محصول هنوز پیاده‌سازی نشده؛ الگوی لینک یا API رسمی دایان در این بررسی قابل تأیید نبود. ابتدا باید لینک‌های شخصی واقعی را در فایل نگاشت وارد کرد. پست‌های بدون لینک معتبر در صف می‌مانند و منتشر نمی‌شوند.

برای فعال‌سازی و تنظیم اسرار GitHub، فایل ACTIVATION.md را دنبال کن. متغیر صحیح فعال‌سازی نسخه نهایی DAYAN_AFFILIATE_RELAY_ENABLED است.
