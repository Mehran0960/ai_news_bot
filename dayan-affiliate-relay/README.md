# Dayan Affiliate Relay

ابزار مستقل برای پایش عمومی @Dayan_video و انتشار ویدئوهای جدید در @Iran_gajet با لینک افیلیت FastCart شخصی.

- Workflow تشخیصی: .github/workflows/dayan-relay-diagnostics.yml — فقط خواندن منبع، بدون انتشار.
- Workflow اصلی: .github/workflows/dayan-affiliate-relay-live.yml — پایش هر ۳۰ دقیقه، حداکثر ۸ ویدئو در روز.
- کد: dayan-affiliate-relay/relay_botapi.py
- راهنمای فعال‌سازی: dayan-affiliate-relay/ACTIVATION.md

## ایمنی

- شروع اول فقط baseline می‌سازد؛ پست قدیمی به‌صورت انبوه بازنشر نمی‌شود.
- فقط ویدئوهای واقعی با لینک مستقیم و کد محصول صریح وارد صف می‌شوند. عکس و پیام متنی نادیده گرفته می‌شوند.
- کد محصول از عبارت صریح «کد» استخراج می‌شود تا قیمت، اندازه و اعداد دیگر به‌جای کد استفاده نشوند.
- لینک شخصی با الگوی FastCart دایان و دامنه فروشگاه خود کاربر ساخته می‌شود.
- توکن ربات و دامنه شخصی در GitHub Actions Secrets هستند؛ URLهای موقتی رسانه و لینک‌های شخصی در state.json ثبت نمی‌شوند.
- اگر منبع ویدئو در دسترس نگذارد یا Telegram نتواند آن را از URL بخواند، اجرا خطا می‌دهد و نباید این را موفقیت فرض کرد.

## وضعیت فعلی منبع

در یک بررسی محدود در ۱۴ اکتبر ۲۰۲۶، آخرین پیام‌های به‌دست‌آمده از @Dayan_video مربوط به ۲۴ تا ۲۶ سپتامبر بودند و ۱۰ پیام بررسی‌شده شامل ویدئوی قابل‌ارسال نبودند. بنابراین تا زمانی که منبع محتوای ویدئویی جدید منتشر نکند، صف انتشار خالی خواهد ماند. این نتیجه فقط مربوط به نمونه بررسی‌شده است؛ پایش بعدی تغییر وضعیت را مشخص می‌کند.

برای تنظیم Token و Store Host به ACTIVATION.md مراجعه کن.
