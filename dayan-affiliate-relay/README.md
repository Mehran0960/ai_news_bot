# Dayan Affiliate Relay

هدف: بررسی کانال عمومی @Dayan_video هر ۳۰ دقیقه، صف‌کردن ویدئوهای تازه و انتشار حداکثر ۸ ویدئو در روز در کانال مقصد، با لینک افیلیت شخصی.

این ابزار فقط ویدئوهای تازه پس از فعال‌سازی را بررسی می‌کند. در اولین اجرا، آخرین شناسه پیام ذخیره می‌شود تا محتوای قدیمی ناگهان بازنشر نشود.

## بسیار مهم

- لینک اختصاصی هر محصول باید از پنل افیلیت خودت گرفته شود. هیچ الگوی URL برای ساخت خودکار لینک دایان حدس زده نشده است.
- پیام دارای دقیقاً یک کد محصول، وقتی آن کد در config/affiliate_links.json لینک معتبر داشته باشد، قابل انتشار خودکار است.
- اگر کپشن چند کد محصول داشته باشد، برای جلوگیری از لینک اشتباه باید در config/post_overrides.json شناسه پیام مبدأ را به کد درست وصل کنی.
- پست‌های فاقد لینک معتبر در صف می‌مانند و منتشر نمی‌شوند.
- سیستم محتوای ویدئویی را از حساب تلگرام احراز هویت‌شده می‌خواند و در کانال مقصد از همان حساب می‌فرستد. آن حساب باید اجازه انتشار در کانال مقصد داشته باشد.
- نشست Telethon دسترسی به حساب تلگرام می‌دهد. آن را در چت نفرست و در مخزن کد ذخیره نکن؛ فقط در GitHub Actions Secrets نگهداری کن. حساب جداگانه برای این کار امن‌تر است.

## تنظیم لینک‌ها

فایل config/affiliate_links.json را با لینک‌های واقعی پنل خودت پر کن. نمونه ساختار (از URL واقعی خودت استفاده کن):

{
  "38933": "https://YOUR-PERSONAL-AFFILIATE-URL",
  "29095": "https://YOUR-OTHER-PERSONAL-AFFILIATE-URL"
}

اگر یک پست چندین کد محصول دارد، شناسه پیام آخر URL تلگرام را در config/post_overrides.json به کد منتخب وصل کن:

{
  "20895": "38933"
}

در لینک t.me/Dayan_video/20895 شناسه پیام 20895 است.

## آماده‌سازی نشست تلگرام از اندروید

1. از https://my.telegram.org وارد بخش API development tools شو و API ID و API HASH خودت را بگیر.
2. در Termux نصب‌شده روی گوشی، Python را نصب کن؛ سپس فایل make_session.py را از همین مخزن دانلود کن و Telethon را نصب کن.
3. اسکریپت را اجرا کن؛ کد ورود تلگرام و در صورت فعال بودن رمز دومرحله‌ای را فقط در Termux وارد کن. اسکریپت یک StringSession چاپ می‌کند. آن را فقط در GitHub Secret ذخیره کن.
4. نشست چاپ‌شده را به من یا هیچ فرد دیگری نفرست.

## تنظیم GitHub

در مخزن GitHub برو به Settings → Secrets and variables → Actions و این Repository secrets را اضافه کن:

- TELEGRAM_API_ID
- TELEGRAM_API_HASH
- TELEGRAM_SESSION
- TARGET_CHANNEL — نام عمومی مقصد مانند @MyChannel یا شناسه کانال

حساب تلگرام مربوط به نشست باید مالک/مدیر کانال مقصد یا دارای مجوز ارسال پیام باشد.

سپس در همان بخش Actions → Variables، متغیر DAYAN_RELAY_ENABLED را با مقدار true بساز. تا قبل از تنظیم secrets و بررسی فایل‌های لینک، آن را فعال نکن.

Workflow در .github/workflows/dayan-affiliate-relay.yml هر ۳۰ دقیقه اجرا می‌شود. انتشار در ساعت‌های 09:00، 11:00، 13:00، 15:00، 17:00، 19:00، 20:30 و 22:00 به وقت تهران برنامه‌ریزی شده است. اجرای GitHub Actions تضمین لحظه‌ای ندارد و ممکن است به تأخیر بیفتد.

## محدودیت فعلی

ساخت لینک دایان خودکار نشده؛ چون API یا قالب رسمی و قابل‌تأیید برای تولید لینک اختصاصی از روی کد محصول در دسترس این پروژه نیست. مرحله فعلی از نگاشت کد به لینک شخصی استفاده می‌کند. اگر پنل تو خروجی CSV یا API رسمی ارائه می‌دهد، این قسمت را می‌توان بعداً خودکار کرد.

## عیب‌یابی

- اولین اجرا فقط baseline می‌سازد و هیچ پیام قدیمی را منتشر نمی‌کند.
- اگر لینک معتبر نباشد یا کد چندگانه/مبهم باشد، ویدئو در صف می‌ماند.
- وضعیت صف و شناسه پیام‌های پردازش‌شده در state.json ثبت می‌شود.
- اگر workflow در هر اجرا خطا داد، GitHub Actions → workflow → Logs را بررسی کن. API ID، API HASH، StringSession و لینک‌های خصوصی را داخل issue یا log منتشر نکن.
