# Dayan Affiliate Relay

ابزار مستقل برای پایش عمومی کانال @Dayan_video هر ۳۰ دقیقه و انتشار حداکثر ۸ ویدئو در روز در کانال مقصد @Iran_gajet، همراه لینک افیلیت شخصی.

## راهنمای شروع
- ابتدا workflow دستی «Dayan Relay Diagnostics» را در GitHub Actions اجرا کن. این آزمون فقط پیش‌نمایش عمومی را می‌خواند و هیچ پستی منتشر نمی‌کند.
- راهنمای کامل اتصال را در ACTIVATION.md ببین.
- workflow زمان‌بندی‌شده در .github/workflows/dayan-affiliate-relay-live.yml است و تا فعال‌سازی صریح خاموش می‌ماند.

## رفتار ایمن
- اولین اجرای live فقط baseline را ثبت می‌کند و پست‌های قدیمی را بازنشر نمی‌کند.
- فقط ویدئوهای جدید وارد صف می‌شوند؛ اطلاعیه‌ها و پست‌های بدون ویدئوی مستقیم نادیده گرفته می‌شوند.
- لینک شخصی باید برای کد محصول روشن باشد؛ پست مبهم یا فاقد لینک معتبر منتشر نمی‌شود.
- صف کپشن، کد و شناسه پیام را نگه می‌دارد؛ URLهای موقتی CDN در فایل عمومی state.json ذخیره نمی‌شوند و پیش از انتشار دوباره خوانده می‌شوند.
- پست شامل لینک افیلیت و افشای همکاری در فروش است.
- پروژه از پیش‌نمایش عمومی Telegram استفاده می‌کند؛ بدون Termux، بدون ورود به حساب شخصی و بدون فراخوانی Actor پولی Apify.

## فایل‌های مهم
- relay_botapi.py: دریافت پیش‌نمایش، صف، نگاشت لینک و انتشار از طریق Telegram Bot API.
- config/affiliate_links.json: فایل جایگزین محلی؛ در GitHub Actions لینک‌ها از Secret خصوصی AFFILIATE_LINKS_JSON خوانده می‌شوند.
- config/post_overrides.json: نگاشت دستی برای پست‌هایی که چند کد محصول دارند.
- state.json: وضعیت پردازش و صف.

## امنیت
توکن ربات را فقط در GitHub Actions Secrets با نام TELEGRAM_BOT_TOKEN نگهدار. لینک‌های شخصی را نیز در Secret جداگانه AFFILIATE_LINKS_JSON قرار بده. این مقادیر را در چت یا فایل‌های عمومی قرار نده.
