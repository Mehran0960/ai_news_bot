# OfferChin / آفِرچین

**سند مرجع و نقطهٔ بازیابی پروژه:** [راهنمای جامع فارسی](../docs/OFFERCHIN_PROJECT_HANDBOOK_FA.md)

هدف جاری، پایش چرخه‌ای تمام صفحه‌های قابل‌دسترسی کاتالوگ عمومی دیجی‌کالا و انتخاب سراسری بر اساس **بیشترین درصد تخفیف واقعی، سپس مبلغ صرفه‌جویی** است. هیچ شاخص تقاضا، محبوبیت، دسته، برند، تعداد نظر، رتبهٔ پرفروش یا کلیک کانال نباید تخفیف بالاتر را عقب بیندازد.

اسکنر از صف پایدار صفحه‌ها، pagination بدون سقف عمق و retry خطاها استفاده می‌کند. shortlist عملیاتی برای کنترل اندازهٔ Git محدود است؛ این محدودیت، سقف اسکن صفحه‌ها نیست. کنترل‌های صحت قیمت، موجودی، تخفیف واقعی، لینک افیلیت و ایمنی انتشار حفظ می‌شوند.

برای معماری، رسانه‌ها، cadence، محدودیت‌های فنی، تست‌ها و مراحل بعدی، ابتدا handbook را بخوانید. دفترهای قدیمی demand-first صرفاً سابقهٔ تاریخی‌اند.
