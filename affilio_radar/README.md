# Affilio Product Radar

این ماژول، منبع مستقلی از دایان و TrendsUploader است. نامزدهای محصول را از صفحات عمومی جست‌وجوی دیجی‌کالا کشف می‌کند، عنوان/تصویر/قیمت/امتیاز کاربران را استخراج می‌کند، وضعیت موجودی را محافظه‌کارانه بررسی می‌کند و یک امتیاز اولویت قابل توضیح می‌سازد.

## چرا لینک افیلیت داخل فایل جداست؟

لینک‌های ردیابی باید از پنل رسمی ناشر افیلیو ساخته شوند. این پروژه **پارامتر یا شناسهٔ افیلیت را حدس نمی‌زند** و برای ساخت لینک وارد حساب کاربری نمی‌شود. هر محصول فقط وقتی امکان انتشار دارد که لینک HTTPS اختصاصیِ تأییدشده‌اش در `config/products.json` ثبت شده باشد.

نمونهٔ ساختار (از لینک واقعی ساخته‌شده در پنل خودت استفاده کن، نه لینک نمونه):

```json
{
  "products": [
    {
      "product_url": "https://www.digikala.com/product/dkp-1234567/",
      "affiliate_url": "https://<your-real-affilio-tracked-link>"
    }
  ]
}
```

هر دو آدرس باید متعلق به همان محصول باشند. لینک افیلیو محرمانهٔ حساب نیست، ولی نباید لینک ساختگی باشد.

## رفتار ایمنی

- کشف نامزدها از ۸ جست‌وجوی فارسی انجام می‌شود؛ نتایج و دلایل امتیازدهی در `candidates.json` ثبت می‌شوند.
- امتیاز، تخمین شفاف است: دستهٔ کالا، بازهٔ قیمت، تخفیف قابل‌تشخیص، امتیاز و تعداد نظرهای عمومی؛ **رتبه‌بندی قطعی فروش یا تضمین درآمد نیست**.
- انتشار فقط وقتی مجاز است که موجودی صریحاً تأیید شود، قیمت و تصویر وجود داشته باشند و لینک افیلیتِ از قبل ساخته‌شده برای همان محصول موجود باشد. موجودی نامعلوم یا ناموجود به معنی عدم انتشار است.
- برای محصولات تأییدشده، از تصویر واقعی محصول یک ویدئوی کوتاه فارسی ۹:۱۶ ساخته می‌شود؛ ادعای ساختگی دربارهٔ کیفیت، فروش یا ویژگی کالا اضافه نمی‌شود.
- در کپشن، قیمت روز، منبع لینک خرید، اخطار تغییر قیمت/موجودی و شفاف‌سازی همکاری در فروش درج می‌شود.
- پیش‌فرض اجرای دستی، فقط بررسی است و هیچ پستی نمی‌فرستد. اجرای زمان‌بندی‌شده می‌تواند حداکثر یک ویدئو در هر نوبت منتشر کند؛ فاصلهٔ کلی حداقل ۸ ساعت و فاصلهٔ تکرار هر محصول حداقل ۳۰ روز است.
- لینک خریدِ تأییدشده بررسی نمی‌شود/باز نمی‌شود تا تست‌ها کلیک افیلیت مصنوعی نسازند.
- ماژول و وضعیت آن از پروژهٔ دایان جداست.

## اجرای دستی

GitHub → Actions → **Affilio Product Radar** → Run workflow.
برای بررسی اولیه، `publish=false` بماند. انتشار دستی فقط وقتی مجاز است که حداقل یک جفت URL در `config/products.json` ثبت شده و همهٔ کنترل‌ها پاس شوند.

## Secrets

- `TELEGRAM_BOT_TOKEN`: همان توکن رباتی که مجوز ارسال به `@Iran_gajet` دارد. در GitHub Secrets ذخیره شود؛ داخل فایل قرار نگیرد.
- `AFFILIO_TELEGRAM_CHAT_ID` اختیاری است؛ مقدار پیش‌فرض `@Iran_gajet` است.
- کد/رمز ورود پنل افیلیو لازم نیست.

## محدودیت فعلی

افیلیو API عمومیِ قابل‌استفاده برای تولید خودکار لینک اختصاصی را در مستندات عمومی‌ای که بررسی شد عرضه نکرده است؛ بنابراین مرحلهٔ ساخت لینک فعلاً از پنل رسمی انجام می‌شود. برای نهایی‌کردن روش لینک‌دهی خودکار، باید قالب واقعی لینک ساخته‌شده از حساب تو بررسی شود؛ رمز عبور/توکن ورود لازم نیست و نباید ارسال شود.
