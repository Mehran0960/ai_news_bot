# Affilio Product Radar

این ماژول مستقل از دایان و TrendsUploader است. نامزدهای محصول را از جست‌وجوی عمومی دیجی‌کالا پیدا می‌کند، قیمت/تصویر/امتیاز و موجودی را بررسی می‌کند، محصولات را رتبه‌بندی می‌کند و برای کالای واجد شرایط ویدئوی کوتاه فارسی می‌سازد.

## لینک افیلیت: بدون لینک‌سازی دستی برای هر کالا

**دیگر لازم نیست برای هر محصول URL اختصاصی بسازی یا فایل کاتالوگ را دستی پر کنی.**

افیلیو یک قالب ردیابیِ قابل‌استفادهٔ مجدد برای رسانه دارد. یکپارچه‌سازی عمومی وردپرس افیلیو نشان می‌دهد که URL محصول در بخش `{YOUR_BASE64_ENCODED_URL}` از قالب ردیابی قرار می‌گیرد. رادار این تبدیل را خودکار انجام می‌دهد و URL هر کالای منتخب را در زمان اجرا می‌سازد.

### تنظیم یک‌بارهٔ قالب

در پنل ناشر افیلیو، قالب ردیابیِ رسانه‌ای را که برای کانال ایران گجت ثبت کرده‌ای بگیر؛ قالب باید میزبان `migmig.affilio.ir` و مسیر `/api/v1/Click/` داشته باشد و عبارت دقیق `{YOUR_BASE64_ENCODED_URL}` در آن باقی مانده باشد. از لینک قالب استفاده کن، نه یک لینک نهاییِ مخصوص محصول.

سپس فقط همین یک مقدار را در GitHub ثبت کن:

GitHub → Repository → Settings → Secrets and variables → Actions → New repository secret

- نام: `AFFILIO_LINK_TEMPLATE`
- مقدار: قالب واقعیِ ردیابیِ مخصوص رسانهٔ تو که جای‌نگهدار `{YOUR_BASE64_ENCODED_URL}` در آن هنوز دست‌نخورده است.

این تنظیم یک‌باره است؛ پس از آن سیستم URL محصولات مختلف را خودش به همان قالب متصل می‌کند. **نیازی به رمز عبور پنل، توکن ورود یا لینک‌سازی محصول‌به‌محصول نیست.** قالب شخصی را در گزارش‌های عمومی یا فایل‌های مخزن قرار نده؛ آن را فقط به‌صورت Secret نگه دار.

## رفتار سیستم

- اجرای زمان‌بندی‌شده هر ۶ ساعت؛ همچنین امکان اجرای دستی از GitHub Actions
- جست‌وجوی ۸ عبارت فارسی برای کشف محصولات محبوب و کاربردی
- اولویت‌بندی با دستهٔ محصول، بازهٔ قیمت، تخفیف قابل‌تشخیص، امتیاز و تعداد نظرهای عمومی
- بررسی موجودی با API عمومی و صفحهٔ محصول؛ وضعیت ناموجود یا نامشخص، منتشر نمی‌شود
- فقط وقتی لینک ردیابی از قالب مجاز ساخته شده باشد، قیمت و تصویر معتبر باشند و موجودی صریحاً تأیید شود، انتشار مجاز است
- برای هر محصول، ویدئوی کوتاه عمودی فارسی از تصویر واقعی محصول ساخته می‌شود
- کپشن شامل نام محصول، قیمت، امتیاز در صورت وجود، لینک خرید و اعلام شفاف همکاری در فروش است
- حداکثر یک ویدئو در هر اجرای زمان‌بندی‌شده؛ فاصلهٔ کلی حداقل ۸ ساعت و فاصلهٔ تکرار هر محصول حداقل ۳۰ روز
- لینک ردیابی ساخته‌شده برای آزمایش باز نمی‌شود تا کلیک مصنوعی در آمار افیلیت ثبت نشود
- قالب لینک فقط در حافظهٔ زمان اجرا استفاده می‌شود و نباید در `candidates.json` یا لاگ‌ها چاپ شود

## موارد اختیاری

`affilio_radar/config/products.json` فقط برای استثناهای دستیِ اختیاری نگه داشته شده است. استفاده از آن لازم نیست؛ وقتی قالب `AFFILIO_LINK_TEMPLATE` تنظیم شده باشد، لینک محصولات جدید به‌طور خودکار ساخته می‌شود.

## Secrets لازم

- `TELEGRAM_BOT_TOKEN`: توکن رباتی که مجاز به ارسال در `@Iran_gajet` است
- `AFFILIO_LINK_TEMPLATE`: قالب عمومی ردیابی رسانه که فقط یک‌بار از پنل ناشر افیلیو تنظیم می‌شود

نام کاربری/رمز عبور پنل افیلیو لازم نیست. هیچ اطلاعات ورود را در کد قرار نده.

## آزمایش و کنترل ایمنی

- تست‌ها ساخت لینک از قالب عمومی، رد دامنه/قالب نامعتبر، تشخیص موجودی، امتیازدهی و رندر ویدئوی MP4 را پوشش می‌دهند.
- هر push کد را با حالت بدون انتشار اجرا می‌کند.
- اجرای زمان‌بندی‌شده فقط زمانی امکان انتشار دارد که قالب ردیابی معتبر حاضر باشد و کنترل‌های محصول پاس شوند.
- امتیاز تقاضا تخمینی است و تضمین فروش نیست.

Workflow:
GitHub → Actions → **Affilio Product Radar**.
