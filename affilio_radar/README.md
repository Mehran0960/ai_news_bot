# OfferChin / آفِرچین

**سند مرجع و نقطهٔ بازیابی پروژه:** [راهنمای جامع فارسی](../docs/OFFERCHIN_PROJECT_HANDBOOK_FA.md)

هدف جاری، پایش چرخه‌ای تمام صفحه‌های قابل‌دسترسی کاتالوگ عمومی دیجی‌کالا و انتخاب بر اساس **شواهد تقاضای بازار از رتبهٔ تازهٔ پرفروش دیجی‌کالا، حرکت رتبه/پوشش دسته، شواهد کمکی نظر و امتیاز، و در نهایت تخفیف واقعی و مبلغ صرفه‌جویی** است. درآمد افیلیت و کلیک کانال در رتبه‌بندی تقاضا دخالت ندارند. رتبهٔ پرفروش سیگنال نسبی دسته است، نه تعداد مطلق واحدهای فروش.

اسکنر از صف پایدار صفحه‌ها، pagination بدون سقف عمق و retry خطاها استفاده می‌کند. shortlist عملیاتی برای کنترل اندازهٔ Git محدود است؛ این محدودیت، سقف اسکن صفحه‌ها نیست. کنترل‌های صحت قیمت، موجودی، تخفیف واقعی، لینک افیلیت و ایمنی انتشار حفظ می‌شوند.

برای معماری، رسانه‌ها، cadence، محدودیت‌های فنی، تست‌ها و مراحل بعدی، ابتدا handbook را بخوانید. سیاست تخفیف‌محور قدیمی فقط سابقهٔ تاریخی است و با سیاست تقاضامحور ۹ نوامبر جایگزین شده است.
