# دسترسی امن به گزارش‌های افیلیو و سنجش عملکرد OfferChin

آخرین بررسی مستندات عمومی: ۲۵ اکتبر ۲۰۲۶.

## وضعیت دسترسی

- پنل ناشران: https://publisher.affilio.ir/
- افیلیو می‌گوید گزارش عملکرد و درآمد ناشر از داخل پنل قابل بررسی است.
- در مستندات عمومی قابل‌دسترسی، API عمومی مستند برای خواندن گزارش ناشر یا توکن read-only پیدا نشد. این به معنی ناممکن بودن API خصوصی نیست؛ پشتیبانی باید وجود آن را تأیید کند.
- اطلاعات ورود، کد یک‌بارمصرف، کوکی نشست یا توکن ناشناس نباید در چت، فایل عمومی GitHub، گزارش CI یا کد منبع قرار بگیرد.

## درخواست پیشنهادی از پشتیبانی

نشانی رسمی اعلام‌شده برای ارتباط: support@affilio.ir

موضوع: درخواست گزارش‌گیری خودکار و تفکیک عملکرد رسانه‌ها برای حساب ناشر OfferChin

متن پیشنهادی:

سلام وقت بخیر،

من ناشر افیلیو با رسانهٔ OfferChin هستم و برای بهینه‌سازی عملکرد لینک‌های همکاری در فروش، قصد دارم گزارش‌های حساب ناشر را به‌صورت منظم تحلیل کنم.

لطفاً بفرمایید آیا برای حساب ناشر، روش رسمی و مجازی برای دریافت خودکار گزارش‌ها وجود دارد؟ ترجیح من یکی از این موارد است:

۱. API رسمیِ فقط‌خواندنی (read-only) با حداقل دسترسی لازم؛
۲. خروجی CSV یا Excel قابل‌دانلود، یا گزارش زمان‌بندی‌شده؛
۳. راهکار رسمی برای تفکیک کلیک، سفارش و کمیسیون به ازای هر رسانه یا منبع انتشار.

به‌طور مشخص، لطفاً توضیح دهید:
- آیا SubID یا پارامتر انتساب منبع در لینک عمومی ناشر قابل استفاده است؟ اگر بله، قالب رسمی و نمونهٔ تأییدشدهٔ آن چیست؟
- آیا گزارش می‌تواند کلیک، سفارش، وضعیت تأیید/رد/لغو، مبلغ فروش، کمیسیون، فروشگاه، محصول و زمان ثبت را نشان دهد؟
- آیا می‌توان داده‌ها را به تفکیک تلگرام، بله، آپارات و یوتیوب گزارش گرفت؟
- در صورت ارائه API، چه روش احراز هویت، محدودیت درخواست و شرایط امنیتی باید رعایت شود؟

من فقط دسترسی گزارش‌گیریِ مجاز و خواندنی می‌خواهم؛ نیازی به دسترسی تغییردهنده به حساب یا ایجاد لینک خارج از قالب رسمی نیست.

سپاسگزارم.

## مسیر موقت تا پاسخ پشتیبانی

اگر پنل گزینهٔ خروجی فایل دارد:
1. گزارش عملکرد/رسانه و گزارش سفارش‌ها/کمیسیون را برای ۳۰ و ۹۰ روز اخیر خروجی بگیر.
2. اگر امکان انتخاب ستون وجود دارد، این موارد را نگه دار: تاریخ و ساعت، فروشگاه، محصول یا شناسهٔ محصول، نام رسانه/منبع/SubID، کلیک، سفارش، وضعیت سفارش، مبلغ فروش و کمیسیون تأییدشده/در انتظار/ردشده.
3. فایل CSV یا XLSX را همین‌جا ضمیمه کن. برای تحلیل، نیازی به رمز ورود یا کوکی نیست.
4. گزارش را با داده‌های داخلی OfferChin تطبیق می‌دهم: کلیک به سفارش، نرخ تبدیل، کمیسیون به‌ازای کلیک، درآمد هر هزار کلیک، محصولات پربازده و تفاوت عملکرد رسانه‌ها.

اگر خروجی فایل در پنل وجود ندارد، از صفحهٔ گزارش و سفارش‌ها اسکرین‌شات بگیر یا از پشتیبانی دربارهٔ امکان خروجی درخواست کن.

## نکتهٔ مهم دربارهٔ ردیاب داخلی OfferChin

ردیاب داخلی، کلیک‌های قابل‌شمارش را به تفکیک محصول و منبع انتشار در Cloudflare KV ثبت می‌کند و اطلاعاتی مانند IP یا نشانی کامل لینک افیلیو را ذخیره نمی‌کند. مسیر عمومی آمار فقط جمع کلیک هر محصول را می‌دهد؛ جزئیات منبع از طریق اتصال مجاز Cloudflare قابل تحلیل است. این آمار، **جایگزین گزارش سفارش و کمیسیون افیلیو نیست**. تا زمانی که افیلیو SubID/منبع را رسماً پشتیبانی نکند یا گزارش سفارش قابل‌تطبیق ندهد، نباید هر سفارش را به‌صورت قطعی به یک کانال نسبت دهیم.

اگر API رسمی ارائه شود، توکن فقط در GitHub Actions Secrets یا Cloudflare Secrets با حداقل دسترسی لازم نگهداری می‌شود؛ هرگز در کد یا فایل عمومی ذخیره نمی‌شود.
