# دسترسی امن به گزارش‌های افیلیو و سنجش عملکرد OfferChin

آخرین بازبینی: ۱۳ نوامبر ۲۰۲۶.

## منبع حقیقت و تفسیر داده

- مرجع آمار کلیک، سفارش، مبلغ فروش و کمیسیون، داشبورد ناشر افیلیو است: https://publisher.affilio.ir/ . صاحب حساب تأیید کرده است که این شاخص‌ها در پنل نمایش داده می‌شوند.
- بنابراین null در performance_report.json به معنی «در گزارش داخلی OfferChin هنوز دریافت/محاسبه نشده» است؛ به معنی صفر سفارش یا صفر فروش نیست. کلیک‌های Cloudflare نیز به‌تنهایی معادل کلیک ثبت‌شده در افیلیو یا سفارش منتسب‌شده نیستند.
- ورود پنل در بررسی ۱۳ نوامبر به SSO دیجی‌وایز در دامنهٔ sso.digiwise.ir هدایت شد. API عمومی مستند فقط‌خواندنی همچنان تأیید نشده؛ وجود endpointهای داخلی در شبکهٔ پنل به‌خودی‌خود مجوز استفادهٔ پایدار یا API رسمی ایجاد نمی‌کند.

## اعتبارنامه‌های موجود در GitHub

صاحب حساب اعلام کرده GitHub Secrets زیر را در تنظیمات مخزن قرار داده است:

- AFFILIO_USER
- AFFILIO_PASS

اتصال GitHub در این ابزار امکان خواندن مقدار Secretها را ندارد؛ مقدار آن‌ها نباید از کاربر خواسته شود یا در چت، کد، log، خروجی تست یا artifact افشا شود. workflow باید فقط در runtime وجودشان را بدون چاپ مقدار کنترل کند. برای هر توکن/کوکی نیز همین قاعده برقرار است.

## مسیر آزمایشی فعلی

- شاخه: audit/affilio-dashboard-readonly
- workflow: .github/workflows/affilio-dashboard-readonly.yml
- اسکریپت: scripts/audit_affilio_dashboard.mjs
- این workflow فقط احراز هویت و بازکردن صفحات گزارش را انجام می‌دهد؛ هیچ سفارش، لینک، کمپین، رسانه یا تنظیمی را تغییر نمی‌دهد.
- فقط metadata صفحه، endpointهای JSON، ساختار پاسخ و مقادیر عددیِ کلیدهای آماریِ مجاز در artifact کوتاه‌عمر ذخیره می‌شود. cookie، token، header، query string، متن کامل صفحه، دادهٔ مشتری و شناسه‌های شخصی ذخیره نمی‌شوند.
- اگر ورود به OTP/CAPTCHA یا تأیید انسانی نیاز پیدا کند، فرآیند متوقف می‌شود؛ هیچ مکانیزم امنیتی دور زده نمی‌شود.
- وضعیت این آزمایش و نتیجهٔ واقعی آن در changelog/PR ثبت می‌شود. تا پیش از تأیید artifact، اتصال نهایی به گزارش‌های تولیدی کامل محسوب نمی‌شود.

## مدل دادهٔ پیشنهادی پس از تأیید پنل

گزارش باید دست‌کم این‌ها را جداگانه ثبت کند: بازهٔ زمانی، فروشگاه، کلیک افیلیو، سفارش ثبت‌شده، سفارش تأییدشده/ردشده/لغوشده، مبلغ فروش، کمیسیون در انتظار و کمیسیون تأییدشده. جمع کل، تفکیک رسانه و تفکیک محصول باید از خود پنل استخراج شود؛ در نبود SubID/انتساب رسمی، فروش محصول/رسانه به‌عنوان attribution قطعی گزارش نمی‌شود.

شاخص‌های تصمیم‌گیری: تعداد سفارش تأییدشده، مبلغ فروش منتسب، کمیسیون تأییدشده، تبدیل کلیک به سفارش (فقط با تعریف مخرج/صورت هم‌دوره و منبع یکسان)، کمیسیون به‌ازای کلیک و سهم هر رسانه. کلیک و بازدید به‌تنهایی معیار موفقیت نهایی کسب‌وکار نیست.

## درخواست از پشتیبانی در صورت نیاز

در صورت نبود خروجی قابل‌اتکا یا endpoint پایدار، از پشتیبانی رسمی Affilio دربارهٔ API read-only، خروجی زمان‌بندی‌شدهٔ CSV/XLSX و امکان SubID یا گزارش تفکیک‌شدهٔ رسانه سؤال شود. از endpoint داخلیِ کشف‌شده بدون تأیید رسمی، به‌عنوان قرارداد دائمی استفاده نشود.
