# دسترسی امن به گزارش‌های افیلیو و سنجش عملکرد OfferChin

آخرین بررسی مستندات عمومی: ۲۵ اکتبر ۲۰۲۶.

## وضعیت دسترسی

- پنل ناشران: https://publisher.affilio.ir/
- افیلیو می‌گوید گزارش عملکرد و درآمد ناشر از داخل پنل قابل بررسی است.
- در مستندات عمومی قابل‌دسترسی، API عمومی مستند برای خواندن گزارش ناشر یا توکن read-only پیدا نشد. این به معنی ناممکن بودن API خصوصی نیست؛ پشتیبانی باید وجود آن را تأیید کند.
- اطلاعات ورود، کد یک‌بارمصرف، کوکی نشست یا توکن ناشناس نباید در چت، فایل عمومی GitHub، گزارش CI یا کد منبع قرار بگیرد.

## درخواست پیشنهادی از پشتیبانی

نشانی رسمی اعلام‌شده برای ارتباط: support@affilio.ir

موضوع: درخواست گزارش‌گیری خودکار و تفکیک عملکرد رسانه‌ها برای حساب ناشر OfferChin

متن پیشنهادی:

سلام وقت بخیر،

من ناشر افیلیو با رسانهٔ OfferChin هستم و برای بهینه‌سازی عملکرد لینک‌های همکاری در فروش، قصد دارم گزارش‌های حساب ناشر را به‌صورت منظم تحلیل کنم.

لطفاً بفرمایید آیا برای حساب ناشر، روش رسمی و مجازی برای دریافت خودکار گزارش‌ها وجود دارد؟ ترجیح من یکی از این موارد است:

۱. API رسمیِ فقط‌خواندنی (read-only) با حداقل دسترسی لازم؛
۲. خروجی CSV یا Excel قابل‌دانلود، یا گزارش زمان‌بندی‌شده؛
۳. راهکار رسمی برای تفکیک کلیک، سفارش و کمیسیون به ازای هر رسانه یا منبع انتشار.

به‌طور مشخص، لطفاً توضیح دهید:
- آیا SubID یا پارامتر انتساب منبع در لینک عمومی ناشر قابل استفاده است؟ اگر بله، قالب رسمی و نمونهٔ تأییدشدهٔ آن چیست؟
- آیا گزارش می‌تواند کلیک، سفارش، وضعیت تأیید/رد/لغو، مبلغ فروش، کمیسیون، فروشگاه، محصول و زمان ثبت را نشان دهد؟
- آیا می‌توان داده‌ها را به تفکیک تلگرام، بله، آپارات و یوتیوب گزارش گرفت؟
- در صورت ارائه API، چه روش احراز هویت، محدودیت درخواست و شرایط امنیتی باید رعایت شود؟

من فقط دسترسی گزارش‌گیریِ مجاز و خواندنی می‌خواهم؛ نیازی به دسترسی تغییردهنده به حساب یا ایجاد لینک خارج از قالب رسمی نیست.

سپاسگزارم.

## مسیر موقت تا پاسخ پشتیبانی

اگر پنل گزینهٔ خروجی فایل دارد:
1. گزارش عملکرد/رسانه و گزارش سفارش‌ها/کمیسیون را برای ۳۰ و ۹۰ روز اخیر خروجی بگیر.
2. اگر امکان انتخاب ستون وجود دارد، این موارد را نگه دار: تاریخ و ساعت، فروشگاه، محصول یا شناسهٔ محصول، نام رسانه/منبع/SubID، کلیک، سفارش، وضعیت سفارش، مبلغ فروش و کمیسیون تأییدشده/در انتظار/ردشده.
3. فایل CSV یا XLSX را همین‌جا ضمیمه کن. برای تحلیل، نیازی به رمز ورود یا کوکی نیست.
4. گزارش را با داده‌های داخلی OfferChin تطبیق می‌دهم: کلیک به سفارش، نرخ تبدیل، کمیسیون به‌ازای کلیک، درآمد هر هزار کلیک، محصولات پربازده و تفاوت عملکرد رسانه‌ها.

اگر خروجی فایل در پنل وجود ندارد، از صفحهٔ گزارش و سفارش‌ها اسکرین‌شات بگیر یا از پشتیبانی دربارهٔ امکان خروجی درخواست کن.

## نکتهٔ مهم دربارهٔ ردیاب داخلی OfferChin

ردیاب داخلی، کلیک‌های قابل‌شمارش را به تفکیک محصول و منبع انتشار در Cloudflare KV ثبت می‌کند و اطلاعاتی مانند IP یا نشانی کامل لینک افیلیو را ذخیره نمی‌کند. مسیر عمومی آمار فقط جمع کلیک هر محصول را می‌دهد؛ جزئیات منبع از طریق اتصال مجاز Cloudflare قابل تحلیل است. این آمار، **جایگزین گزارش سفارش و کمیسیون افیلیو نیست**. تا زمانی که افیلیو SubID/منبع را رسماً پشتیبانی نکند یا گزارش سفارش قابل‌تطبیق ندهد، نباید هر سفارش را به‌صورت قطعی به یک کانال نسبت دهیم.

اگر API رسمی ارائه شود، توکن فقط در GitHub Actions Secrets یا Cloudflare Secrets با حداقل دسترسی لازم نگهداری می‌شود؛ هرگز در کد یا فایل عمومی ذخیره نمی‌شود.

## وضعیت اتصال و حفاظت داده — بازبینی ۱۳ نوامبر ۲۰۲۶

- ورود واقعی به پنل ناشر با GitHub Secrets `AFFILIO_USER` و `AFFILIO_PASS` تأیید شده است. مقادیر secretها قابل خواندن از اتصال GitHub نیستند و نباید در چت درخواست یا افشا شوند.
- workflow نسخهٔ read-only فقط درخواست‌های GET/بازکردن صفحات و تب‌های گزارش را اجرا می‌کند؛ هیچ سفارش، کمپین، لینک یا تنظیمی تغییر نمی‌دهد.
- گزارش حاوی دادهٔ خصوصی با AES-256-GCM و کلیدی مشتق‌شده از secret رمز می‌شود؛ فقط ciphertext به‌عنوان artifact با retention هفت‌روزه ذخیره می‌شود. دو artifact تشخیصی اولیه که در تست توسعه به‌صورت plaintext ایجاد شده بودند، در همان روز با موفقیت حذف شدند؛ run نهایی encrypted-only است. هیچ رمز، کوکی یا token در لاگ/فایل ذخیره نمی‌شود.
- snapshot اولیه در بازهٔ ۱۶ تا ۲۲ آبان ۱۴۰۵، کلیک و درآمد پنل را نشان داد؛ اما «income basket» به‌عنوان سفارش قطعی نام‌گذاری نمی‌شود. فیلدهای سفارش، تأیید/لغو/رد و کمیسیون تأییدشده باید از ساختار واقعی جزئیات گزارش یا خروجی سفارش‌ها استخراج شوند.
- parser فعلی جمع‌های داشبورد و trendها را می‌خواند، اما استخراج ردیف‌های رسانه/لینک هنوز کامل و تأیید نشده است؛ تا آن زمان هیچ سفارش یا کمیسیون به تلگرام/بله/یوتیوب/آپارات منتسب نمی‌شود.
- اجرای آزمایشی روی شاخهٔ مستقل `fix/affilio-dashboard-reporting-v2-20261113` علاوه بر دادهٔ رمز‌شده، فقط نام endpointها و ساختار کلیدها را در لاگ ثبت می‌کند تا parser بدون چاپ مقادیر مالی/اطلاعات کاربر اصلاح شود. زمان‌بندی روزانه فقط پس از ادغام روی main فعال خواهد شد.

## کوکی و انتساب خرید

**مدت کوکی با مدل انتساب یکسان نیست.** شواهد عمومی موجود تا این بازبینی:
- اطلاعیهٔ رسمی افیلیو دربارهٔ پروژهٔ محدود انتشار آگهی در دیوار می‌گوید خریدهای بعدی کاربر تا ۳۰ روز می‌تواند برای صاحب آگهی کمیسیون داشته باشد؛ این ادعا را نباید به همهٔ رسانه‌ها/لینک‌های عادی دیجی‌کالا تعمیم داد.
- مصاحبهٔ قدیمی دربارهٔ سیستم افیلیت سابق دیجی‌کالا از پنجرهٔ ۱۰روزه گفته است؛ به‌دلیل قدمت و تغییر ساختار به افیلیو، مبنای سیاست فعلی نیست.
- قانون کلی و جاری مدت کوکی برای لینک‌های عادی OfferChin، قانون جایگزینی ناشر قبلی با کلیک ناشر جدید (last-click/first-click)، و رفتار ردیابی در بازشدن اپلیکیشن از مرورگر هنوز از منبع رسمی تأیید نشده‌اند.

پرسش‌های لازم از پشتیبانی افیلیو:
1. مدت اعتبار کلیک/شناسهٔ ناشر برای لینک‌های عادی دیجی‌کالا دقیقاً چند روز/ساعت است؟
2. اگر کاربر ابتدا از لینک ناشر A وارد شود و فردا روی لینک ناشر B کلیک کند، شناسهٔ کدام ناشر برای خرید بعدی معتبر می‌ماند؟ آیا پنجره از نو آغاز می‌شود؟
3. اگر کاربر پس از کلیک، دیجی‌کالا را در اپلیکیشن باز کند یا از پیامک/Push خود دیجی‌کالا وارد اپ شود، attribution حفظ می‌شود؟
4. آیا مدت و مدل attribution برای رسانه‌های ثبت‌شدهٔ عادی با پروژهٔ ویژهٔ دیوار/تبلیغات فروشگاهی تفاوت دارد؟
5. آیا گزارش سفارش‌ها امکان تفکیک بر اساس media_id، link_id یا sub_id را می‌دهد؟

**سیاست آزمایش OfferChin:** از cookie stuffing، ریدایرکت پنهان، بازکردن خودکار لینک یا کلیک ساختگی استفاده نمی‌شود. ابتدا پاسخ رسمی و سپس آزمایش کنترل‌شده با کاربر/مرورگر آزمایشی مجاز انجام می‌شود. پیامک و نوتیفیکیشن دیجی‌کالا را باید به‌عنوان «سیگنال قصد خرید/آگاهی از پروموشن» به کار برد: محتوای OfferChin یک نیاز/محصول مرتبط و قیمت نهایی را معرفی کند و کاربر با تصمیم آگاهانه روی لینک افیلییت کلیک کند. صرف دریافت پیامک یا بازکردن مستقیم اپلیکیشن دیجی‌کالا، به‌تنهایی برای OfferChin انتساب یا کمیسیون ایجاد نمی‌کند.
