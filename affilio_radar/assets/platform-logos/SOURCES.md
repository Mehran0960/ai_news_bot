# Official platform logo sources

- Telegram: https://telegram.org/tour/screenshots (official press ZIP; pictorial mark)
- Bale: https://bale.ai/logo/bale_logo.svg (renderer crops the standalone mark)
- Rubika: https://rubika.ir/logo and https://rubika.ir/static/images/logo.svg (renderer crops the multicolor symbol)
- YouTube: https://brand.youtube/youtube-icon/ (official full-color source; renderer keeps only the red play-button icon)
- Aparat: https://www.aparat.com/home (first-party header SVG; renderer keeps only icon-aparatfa)

These pinned files are official/first-party source assets. Some are full lockups; the shared renderer crops the pictorial symbol and never paints platform-name lettering into the cross-media ID rows. Renderers must not fetch logo files from the network.
