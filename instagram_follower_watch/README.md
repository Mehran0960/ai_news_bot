# پایشگر فقط‌خواندنی سرویس‌های فالوور اینستاگرام

این ماژول برای پیج عمومی @Negin.firuzjaei_70 فقط صفحه‌های عمومی دو سرویس را پایش می‌کند و گزارش زمان‌بندی ادعایی، CAPTCHA و زمان اسمی نوبت بعدی را می‌سازد.

## مرزهای اجرایی
- فقط درخواست HTTP GET برای خواندن صفحه‌های عمومی سرویس‌ها انجام می‌شود.
- هیچ فرم، دکمه، سفارش یا درخواست فالووری ارسال نمی‌شود.
- به اینستاگرام وارد نمی‌شود و رمز یا کوکی اینستاگرام دریافت نمی‌کند.
- CAPTCHA حل یا دور زده نمی‌شود.
- حسابی دنبال نمی‌شود و هیچ تعامل یا خریدی انجام نمی‌شود.
- اگر متن رسمی صفحه تغییر کند یا صفحه قابل‌خواندن نباشد، وضعیت «تأییدنشده» گزارش می‌شود؛ زمان‌بندی حدس زده نمی‌شود.

## سرویس‌های پایش‌شده
| سرویس | ادعای منتشرشده | CAPTCHA | نکته |
|---|---:|---|---|
| SMM8 | ۱۰ فالوور در هر ۳۰ دقیقه؛ حدود ۴۸۰ در روز | در متن عمومی مشاهده نشد؛ تایمر داخلی دارد | محدودیت مستقل IP/پروفایل دقیقاً تفکیک نشده |
| MeFreeSocial | ۱۵ فالوور در هر ۶ ساعت | Cloudflare security check | همان پروفایل هر ۶ ساعت؛ متن صفحه صریحاً بی‌نیازی از ثبت‌نام را تأیید نمی‌کند و وضعیت آن نیمه‌تأیید می‌ماند |

MeFreeSocial مستقیماً فرم نام کاربری عمومی و بدون رمز اینستاگرام دارد، اما چون عبارت صریح «بدون ثبت‌نام» در متن قابل‌مشاهده نیست، اسکریپت آن را آمادهٔ اقدام قطعی اعلام نمی‌کند.

SocialFollow در این پایشگر فعال نیست: دریافت ۱۰۰ فالوور را به دنبال‌کردن ۱۰ حساب دیگر و حفظ آن دنبال‌کردن‌ها مشروط می‌کند؛ این ماژول هیچ تعاملی با حساب انجام نمی‌دهد.

## زمان نوبت بعدی
زمان دقیق فقط در صورتی محاسبه می‌شود که زمان درخواست دستیِ پذیرفته‌شده در فایل state/manual_requests.json ثبت شده باشد. بعد از هر درخواست دستی که سایت پذیرش آن را تأیید کرد، یک timestamp دقیق UTC به آرایهٔ سرویس مربوط اضافه کن:

`2026-10-31T17:42:00Z`

این فقط نمونهٔ قالب است، نه زمان استفادهٔ واقعی.

برای ثبت محلی با اسکریپت:

```bash
python instagram_follower_watch/watch.py record smm8 2026-10-31T17:42:00Z
```

یا فایل JSON را مستقیماً در GitHub ویرایش و commit کن. همهٔ زمان‌ها باید UTC و با پسوند Z باشند. تاریخ ساختگی یا تخمینی وارد نکن.

## اجرای زمان‌بندی‌شده
GitHub Actions هر ۶ ساعت صفحه‌ها را می‌خواند و گزارش را در Actions → Instagram follower service watch → Summary و Artifact قرار می‌دهد. اجرای زمان‌بندی‌شدهٔ GitHub ممکن است چند دقیقه تأخیر داشته باشد؛ بنابراین این سرویس اعلان لحظه‌ای یا تضمین بازشدن سهمیه نیست.

## ریسک سیاست پلتفرم
راهنمای جامعهٔ اینستاگرام جمع‌آوری مصنوعی فالوورها را منع می‌کند. این پایشگر برای ارسال درخواست یا افزایش مصنوعی فالوور طراحی نشده و صرفاً وضعیت عمومی صفحات و نوبت‌های ثبت‌شدهٔ دستی را گزارش می‌کند. استفاده از سرویس‌های ثالث ممکن است به حذف فالوورهای غیرواقعی یا محدودیت حساب منجر شود.
