# MeMarket Affiliate Deal Radar

رادار به‌صورت مستقل از پروژه‌های دیگر، پست‌های عمومی رسمی می‌مارکت را پایش می‌کند و آفرهای واجد شرایط را با لینک همکاری در فروش به تلگرام می‌فرستد.

## Secrets لازم
در GitHub → Settings → Secrets and variables → Actions این ۳ مقدار را ثبت کن:
- MEMARKET_AFFILIATE_CODE
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID

نام کاربری و رمز قدیمی API در نسخه فعلی استفاده نمی‌شوند.

## رفتار
- اجرا هر ۱۵ دقیقه
- منبع: کانال عمومی رسمی می‌مارکت
- تخفیف ۳۰٪+ سیگنال پایه
- تخفیف ۴۰٪+ امتیاز بالاتر
- لینک‌های محصول و Landing رسمی با کد افیلیت شما بازنویسی می‌شوند
- حداکثر ۳ هشدار در هر اجرا
- Cooldown شش‌ساعته برای جلوگیری از اسپم
- اولین اجرای معمولی بدون ارسال آفرهای قدیمی، فقط وضعیت را ثبت می‌کند
- وضعیت در memarket_radar/state.json نگهداری می‌شود

## نکته
این نسخه «رادار آفرهای منتشرشده عمومی» است، نه مانیتور لحظه‌ای کل کاتالوگ قیمت. برای MVP عمداً مسیر پایدار و بدون وابستگی به API قدیمی انتخاب شده است.

## شروع
Workflow اصلی:
Actions → MeMarket Deal Radar

بعد از فعال بودن زمان‌بندی، سیستم به‌صورت خودکار اجرا می‌شود.
