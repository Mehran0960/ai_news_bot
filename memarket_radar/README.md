# MeMarket Affiliate Deal Radar

رادار به‌صورت مستقل از پروژه‌های دیگر، پست‌های عمومی رسمی می‌مارکت را پایش می‌کند و آفرهای واجد شرایط را با لینک همکاری در فروش به تلگرام می‌فرستد.

## Secrets لازم
در GitHub → Settings → Secrets and variables → Actions این ۳ مقدار را ثبت کن:
- MEMARKET_AFFILIATE_CODE
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID

نام کاربری و رمز قدیمی API در نسخه فعلی استفاده نمی‌شوند.

## رفتار
- اجرا هر ۱۵ دقیقه
- منبع: کانال عمومی رسمی می‌مارکت
- تخفیف ۳۰٪+ سیگنال پایه
- تخفیف ۵۰٪+ امتیاز بالاتر
- فقط لینک‌های خریدارِ معتبر روی `memarket24.ir` و `l.memarket.me` پذیرفته می‌شوند
- کد افیلیت در لینک‌های رسمی جایگزین می‌شود؛ در لینک‌های کوتاه `l.memarket.me` کد مسیر هم اصلاح می‌شود
- پیام‌های جذب بازاریاب/پورسانت/کمیسیون فیلتر می‌شوند
- قبل از ارسال، صفحه محصول بررسی می‌شود؛ فقط وقتی نشانه صریح موجودبودن دیده شود آفر ارسال می‌شود. وضعیت نامشخص یا ناموجود رد می‌شود
- تصویر اصلی محصول (در صورت دسترسی) دانلود و به‌صورت فایل به تلگرام آپلود می‌شود؛ عکس تبلیغاتی کانال فقط جایگزین اضطراری است
- دامنه‌های قدیمی `memarketshop.ir` و `mmkt.ir` و زیردامنه‌هایشان به‌علت اعلام خروج از رده، مسدودند
- حداکثر ۳ هشدار در هر اجرا
- Cooldown شش‌ساعته برای جلوگیری از اسپم
- اولین اجرای معمولی بدون ارسال آفرهای قدیمی، فقط وضعیت را ثبت می‌کند
- وضعیت در memarket_radar/state.json نگهداری می‌شود

## نکته
این نسخه «رادار آفرهای منتشرشده عمومی» است، نه مانیتور لحظه‌ای کل کاتالوگ قیمت. بررسی موجودی به اطلاعاتی وابسته است که صفحه عمومی محصول نمایش می‌دهد؛ اگر فروشگاه موجودی را فقط در API احراز هویت‌شده نگه دارد، وضعیت UNKNOWN شده و آفر ارسال نمی‌شود. برای پوشش کامل کاتالوگ، به API رسمی یا دسترسی مجاز پنل نیاز است.

## شروع
Workflow اصلی:
Actions → MeMarket Deal Radar

بعد از فعال بودن زمان‌بندی، سیستم به‌صورت خودکار اجرا می‌شود.
