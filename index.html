دربارهٔ برنامه

این ابزار خصوصی برای خودکارسازی انتشار ویدئوهای کوتاه مرتبط با پیشنهادهای آفِرچین در کانال یوتیوبی است که مدیر آفِرچین کنترل می‌کند. برنامه با مجوز صاحب حساب و از طریق YouTube Data API و گردش‌کارهای خودکار GitHub اجرا می‌شود. این صفحه سرویس عمومی ثبت‌نام یا محصول رسمی Google یا YouTube نیست.

این ابزار برای انتشار ویدئوهای کانال تحت مدیریت صاحب پروژه استفاده می‌شود و برای استفادهٔ عمومی یا اتصال حساب کاربران دیگر ارائه نشده است.

About this application

OfferChin YouTube Uploader is a private automation tool used by the OfferChin project owner to publish short videos to a YouTube channel they control. It uses the YouTube Data API with the account owner's authorization and automated GitHub workflows. It is not a public sign-up service and is not affiliated with Google or YouTube.

The tool is not offered for connecting accounts belonging to other users.
