# ارزیابی آمادگی اتصال دیما به OfferChin
**تاریخ بررسی:** ۱۸ نوامبر ۲۰۲۶  
**وضعیت:** نامزد پایلوت محدود؛ نه آمادهٔ جایگزینی افیلیو و نه متصل به انتشار زنده.

## آنچه آزمایش شد
- لینک عمومی دیما که در اختیار پروژه قرار گرفت، با روش راهنمای لینک عمومی (افزودن مسیر Base64 URL-safe مقصد) آزمایش شد.
- مقصد آزمایش‌شده صفحهٔ اصلی خانومی بود. مقصد نهایی به دامنهٔ خانومی رسید و پارامترهای رهگیری `clickid`، `affiliate=deema` و `refby` در URL مقصد دیده شدند.
- این نتیجه فقط انتقال و صدور شناسهٔ کلیک را ثابت می‌کند؛ افزایش شمارندهٔ کلیک در پنل، سفارش، تأیید سفارش یا کمیسیون تأیید نشده‌اند.
- برای پیدا کردن یک URL عمومیِ محصول خانومی جهت آزمون deep-link، صفحهٔ دسته‌بندی خانومی را بررسی کردم؛ سامانهٔ ضدربات مانع استخراج لینک محصول شد. بنابراین آزمون deep-link از طریق خود دیما هنوز انجام نشده است.
- راهنمای لینک عمومی در اختیار پروژه تاریخ به‌روزرسانی ۷ آذر ۱۴۰۱ دارد. قاعدهٔ Base64 و padding باید پیش از استفادهٔ عملی با یک مقصد محصولی و تنظیمات جاری پنل دوباره تأیید شود.

## مانع مهم انتساب
ردیف‌های پنل ارائه‌شده برای چند لینک دیما، رسانه را «پیندو» نشان می‌دهند. تا زمانی که دیما تأیید نکند این شناسه/رسانه متعلق به OfferChin است، استفاده از همان پایه‌لینک ممکن است فروش را به رسانهٔ دیگری منتسب کند.

پیش از تولید لینک باید در پنل دیما:
1. رسانهٔ مستقل OfferChin با نشانی‌ها و توضیح صحیح ثبت و تأیید شود؛
2. روشن شود یک رسانه برای چند کانال مجاز است یا لازم است برای Telegram، Bale و هر بستر دیگر media/base-link جدا ساخته شود؛
3. پشتیبانی رسمی SubID یا روش انتساب کانال‌به‌کانال مستند شود؛ از پارامترهای حدسی مانند `aff_sub` استفاده نشود.

## API و گزارش فروش
در منابع عمومی رسمی بررسی‌شده، مستند API عمومی قابل اتکایی برای ساخت لینک یا دریافت گزارش سفارش پیدا نشد. براساس راهنمای ارائه‌شده، ساخت URL محصول با Base64 محلی ممکن است و ظاهراً برای تولید هر لینک به API نیاز ندارد؛ اما این موضوع وجود API گزارش سفارش را ثابت نمی‌کند.

گزارش رسمی پنل یا CSV/API باید کلیک، سفارش، وضعیت تأیید/لغو/مرجوعی، مبلغ فروش، کمیسیون نهایی، timestamp و وضعیت تسویه را پوشش دهد. تا پیش از اتصال این گزارش، فروش و کمیسیون نباید از آمار کلیک استنباط شوند.

## گیت‌های قبل از پایلوت
- تأیید کتبی مجازبودن Telegram، Bale، Rubika، Eitaa، YouTube و Aparat برای رسانهٔ ثبت‌شده؛ وضعیت Filo نیز جداگانه پرسیده شود.
- تأیید فروشگاه‌های مجاز و امکان deep-link به URL دقیق محصول.
- تست مستقل کلیک و مشاهدهٔ آن در پنل دیما با همان media صحیح.
- بررسی دسترسی `deemanetwork.com` و دامنهٔ مقصد از داخل ایران و در وضعیت محدودیت اینترنت بین‌الملل؛ موفقیت یک درخواست از محیط خارجی، پایداری در اینترنت ملی را تضمین نمی‌کند.
- تست نمونهٔ سفارش فقط با مجوز و طبق روال رسمی شبکه، بدون سفارش صوری یا خودارجاعی خلاف مقررات.

## تصمیم عملیاتی
دیما فعلاً «نامزد پایلوت» باقی می‌ماند. این بررسی هیچ CTA، لینک افیلیو، secret، حساب ناشر یا انتشار عمومی را تغییر نداده است. پس از تأیید رسانهٔ درست و گزارش سفارش/کمیسیون، می‌توان لینک‌ساز جداگانهٔ Deema را ابتدا در حالت shadow و با allowlist فروشگاه‌ها پیاده کرد؛ جایگزینی لینک‌های فعلی منوط به اثبات انتساب و اقتصاد واقعی سفارش است.
