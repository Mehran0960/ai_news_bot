# سیاست استقلال رسانه‌های OfferChin
**تاریخ:** ۱۷ نوامبر ۲۰۲۶  
**مخزن:** `Mehran0960/ai_news_bot`

## الزام غیرقابل‌مذاکره
هیچ رسانه‌ای نباید برای شروع یا تکمیل انتشار منتظر رسانهٔ دیگر بماند. این قاعده شامل تلگرام، بله، روبیکا، ایتا، یوتیوب، آپارات و فیلو است.

## اجرای مستقل
- مقصدهای عکس (Telegram/Bale/Rubika/Eitaa) هم‌زمان آغاز می‌شوند و هرکدام receipt/status مختص خود را دارند.
- مقصدهای ویدئو (YouTube/Aparat/Filo) با due check و GitHub Actions workflow مستقل Dispatch می‌شوند.
- نوبت کانال/تحریریه، اجرای catalog scan و وضعیت workflow رسانهٔ دیگر، gate انتشار یک مقصد نیست.
- هر Workflow concurrency group مستقل دارد. مرحلهٔ ثبت state می‌تواند برای ادغام امن commitها retry شود، اما این مرحله پس از ارسال خارجی است و نباید شروع یا ارسال مقصدهای دیگر را قفل کند.
- برای جلوگیری از حذف receiptهای هم‌زمان، state JSON با `merge_state_conflicts.py` به‌صورت سه‌طرفه ادغام می‌شود.

## استقلال از گیت‌های ایمنی
استقلال به معنای نادیده‌گرفتن قوانین مقصد نیست. سهمیه API، credential، محدودیت حجم/فرمت و پاسخ رد پلتفرم فقط همان مقصد را تحت تأثیر قرار می‌دهند. اگر YouTube سقف واقعی روزانهٔ API را برگرداند، صف YouTube با زمان retry حفظ می‌شود و پس از cooldown خودکار ادامه می‌یابد؛ این وقفه به Aparat، Filo یا کانال‌های عکس سرایت نمی‌کند. Aparat نیز دیگر به deadline تأییدشدهٔ خرده‌فروش وابسته نیست: آفر باید در مرحلهٔ انتخاب و آخرین بررسی قیمت/موجودی تأیید شده باشد، حداکثر ۲۴ ساعت تازگی داشته باشد و اگر زمان انقضای معتبری موجود است، از حاشیهٔ انقضای ایمن عبور نکرده باشد. نبود credential یا rate limit فقط همان مقصد را متوقف می‌کند.

## معیارهای پذیرش
1. تست‌ها ثابت کنند وضعیت مقصد دیگر پس از merge حفظ می‌شود.
2. هر ویدئو workflow مختص خود را از Worker دریافت کند.
3. ارسال مقصدهای عکس بدون انتظار ترتیبی آغاز شود.
4. failure یک مقصد، status مقصدهای دیگر را تغییر ندهد.
5. انتشار عمومی تنها با receipt، شناسه یا URL واقعی تأیید شود.

## محدودیت عملی
هیچ سیستم بیرونی نمی‌تواند انتشار قطعی را در زمان قطعی اینترنت، رد API، rate limit، تعلیق حساب یا نبود اعتبارنامه تضمین کند. تعهد سامانه این است که این خطاها را محلی نگه دارد، صف مقصدهای سالم را معطل نکند و هر مقصد را مستقل retry کند.
